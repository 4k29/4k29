GitHub下書き保存の初期設定

NotesとMemoryの下書き保存に加えて、Notes Editorから記事用の写真を4k29へアップロードするための設定です。最初の1回だけ行います。

1. 下書き専用リポジトリを作る

  1. GitHubの新規リポジトリ画面を開く
  2. Repository nameを 4k29-editor-drafts にする
  3. Visibilityは必ず Private にする
  4. Add a README fileをオンにして、Create repositoryを押す

2. エディター専用キーを作る

  1. Fine-grained tokenの作成画面を開く
  2. Token nameは 4k29 Editor、Resource ownerは 4k29 にする
  3. Repository accessでOnly select repositoriesを選び、4k29-editor-draftsと4k29の2つを選ぶ
  4. Repository permissionsのContentsをRead and writeにする
  5. Generate tokenを押し、表示されたキーをコピーする

3. エディターを開く

Notes EditorまたはMemory Editorを開き、コピーしたキーを貼り付けます。正しいGitHubアカウントとPrivate設定を確認できたときだけ、編集画面が開きます。

以前のキーで4k29-editor-draftsだけを選んでいる場合は、そのキーをGitHubの設定画面で編集し、対象リポジトリへ4k29も追加してください。キーはパスワードと同じなので、スクリーンショットやチャットへ貼らないでください。
