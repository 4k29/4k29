Noto Sans JP, regular weight 400, SIL Open Font License 1.1.
Source: https://github.com/google/fonts/tree/main/ofl/notosansjp
Upstream font: NotoSansJP[wght].ttf
Instantiated at weight 400 and subset using fontTools 4.66.1 to:
- Japanese punctuation, hiragana and katakana (U+3000-30FF).
- Full-width characters (U+FF00-FFEF).
- JIS X 0208 level-one kanji (EUC-JP rows B0-CF).
- Non-ASCII characters occurring in the site's HTML, CSS, JavaScript and JSON.
Packaged as WOFF2 (573,880 bytes). Served locally; no external font requests.
Other characters fall back to Hiragino Sans, Yu Gothic UI, Meiryo or sans-serif.
The existing Terminal Mono font remains first in the stack for Latin text.
