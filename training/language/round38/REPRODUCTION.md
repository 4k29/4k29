# Round38 corpus-only experiment

The scientific comparator is the completed but unadopted Round37. The initialization is the exact Round28 latest full model/AdamW/Torch/private-Python RNG state (SHA in policy), as in Round37. Public/research adoption remains unchanged.

Only the TRAIN corpus changes: append 4575 original human JMRD official TRAIN dialogues to the pre-existing corpus. The upstream revision, download SHA, attribution, CC-BY-SA license and protected-overlap receipt are retained in added-human-source. No upstream valid/test was downloaded. Original dialog[].text only, joined with newline; no reviews, role tags, questionnaires or generated positives. Public participant IDs are unavailable; no new cross-source speaker-disjointness claim. Movie bias and frequent acknowledgements limit expectations.

Preparation used the existing round28/prepare_addition.py with --base training/language/round37/multiview --sources training/language/round38/added-human-source --out training/language/round38/multiview. Existing TRAIN bytes/index rows, validation and vocabulary remain exact. Derived boundary lists retain every original entry and add only exact existing token ends after original utterance separators. Execution preparation scripts suffixed _as_executed record the operations; they are historical scripts with workspace paths, not a safe rerun-over-existing-artifacts command.

Restore multiview/train.tokens.bin using checkpoint_chunks.py restore multiview/train.tokens.bin.chunks.json if absent. Training uses execution/run.sh (10000 requested updates); use --resume only for an existing partial checkpoint. execute.py locks and rejects duplicate/completed training. Checkpoint counters and result.json determine actual completion, never the requested dose. Selected checkpoint monitoring preserves aligned moments/RNG; selection uses unchanged common mixed-view development NLL.

Corpus addition changes the positive draw population, target counts and possibly RNG consumption. Exact final draw/RNG matching to Round37 is not expected. Independent sampler replay must match this experiment's own checkpoint. Core learning code is byte-identical to Round37, including EOS auxiliary CE and eligible-newline main CE exclusion, teacher and self-rollout unlikelihood. Original language gates and fixed humanDEV/daily guard remain unchanged. No new TEST evaluation or public behavior changes are authorized by preparation.
