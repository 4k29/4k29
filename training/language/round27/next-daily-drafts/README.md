# 日常会話TRAIN追加候補 — 現在のRound27には未使用

実用ジャンルは日常会話。容量だけを変えたRound27の比較後に、このTRAIN追加を別roundで検証する。容量との同時変更をしない。まだ学習用データの作成・tokenize・採用・optimizer更新は行っていない。

TRAIN8992ファイルと、すでに露出したDEV99ファイルだけをhash監査した。予約TESTは未読で、後の学習前に重複監査が必要。別ファイルなのに内部dialogueIdが同じ例があり、ファイルパス+SHAを識別子とする。TRAIN内部は5余剰ファイル、DEV内部は1余剰ファイルの全文重複があった。候補TRAINからhash同一群の辞書順先頭以外を除くと8987ファイル。TRAIN/DEVの32文字以上の発話全文一致は0件だが、近似・部分・短文の重複不在は保証しない。

既存の会話DEV99 NLLは重複を含む99ファイルの固定測定であり、独立99会話として解釈しない。過去の指標を黙って変更しない。原文・採用済み評価・進行中の学習データは変更していない。

候補のserializationは人間発話を改変せず改行で連結し、人物profile・AIログ・模範解答・role名補作を入れない方式を第一候補とする。実際の方式、比率、フィルタ、重複除外、利用条件、コード/データSHAと評価条件は次のround開始前に固定する。教材風/公文書風への話題逸脱と反復を日常場面の全文生成で確認し、NLL低下だけでは採用しない。
