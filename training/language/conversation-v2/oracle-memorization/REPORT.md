# 正しい履歴と文章の記憶による自由生成診断

判定はケース2。基盤3状態では参照原文を最初から32 tokens与えても、そこから自律生成した二文が自然につながった入力は各0/18だった。一方、MIX-579から12の文章を意図的に反復学習すると、通常CEと継続CEの両方が、第一文から残りの複数文を12/12で完全再現した。未知の入力に学習中の固有名詞や言い回しが現れ、文章DEVでの話題保持とcaptionの能力は改善しなかった。

## 正しい参照からの生成

元のprefixと原典BPE列の完全一致を確認し、その直後から0、1、4、8、16、32 tokensを与えた。全324条件が実施可能だった。最大prefix104に32 tokensを加えても、自律生成112 tokensを切り詰めずにcontext256で比較できる。64条件は加えなかった。各状態の0条件は保存済みgreedy列の先頭112 tokens以内と一致。強制部分を得点に含めていない。各系列には原文位置、正解履歴と自律履歴の全stepのtop5、参照token順位と確率、EOS・LF・空白確率、raw bytes、終了理由を収録した。

6段階すべてで3状態とも二文成立は0/18。MIX-579の4-gram再出現は参照0で12件、32で14件。B-14は14件から16件、C-14は18件から18件。C-14に32 tokens与えた場合も、解放後の再出現開始中央値は14.5 tokensだった。同じ条件で、再出現地点が参照比較可能だった16件の原文token確率は、正解履歴で平均7.05%、自己生成履歴で0.36%だった。モデル入力が違うので、この差から意味理解の量は読めない。短い語尾で終了する場合もあり、反復しない系列がそのまま成功になるわけではない。

最初の参照不一致、最初の4-gram再出現、その前後の確率は別々に保存。SEMANTICには三連続サイクルの位置も記録した。これらは観察可能な反復の目印であり、意味の崩れが始まった厳密なtokenは全件で一意に同定できない。実際、完全再現した人間の原文にも12件中5件で4-gramの再使用がある。

## 制御した実学習

既存審査済みのWikibooks 5件、Global Voices人手訳7件を元の並びと帰属つきで使用。12件すべて別familyで、固定文章DEVとのfamily一致は0。過去研究で使用した資料を含む。各文章を第一文の句点とBPE境界が一致する場所で分け、第一文以後に2文以上残ることを確認した。真の文書末EOSを持たない抜粋であり、終了の習得は評価できない。全原文の帰属・license・原典SHAはSOURCE_AUDIT、教師列とprefixはTRAINにある。

各条件は同一MIX-579重み、新規AdamW、seed 12103、LR 1e-4、clip 1.0。固定順で3文章を1 batchとして4更新で一巡した。Bは第一文を入力に残し、第一文までの次token lossだけをマスクした。A/Bの独立有効教師は1,614/1,227、75巡の延べ教師は121,050/92,025。各条件で保持300更新、捨て安全検査1、別プロセスの再開照合用の捨て更新1。計604 optimizer呼出し。100から101への更新はlossだけでなくmodel・Adam・torch RNGのdigestが一致した。clipはAが169/300、Bが148/300。更新ごとの勾配ノルム・埋め込み更新ノルム・実教師数をledgerに収録した。

100更新の通常CEでは、イランのゲーム制作について、調査からプレイヤーの選択による物語の変化につなぐ二文ができた。ただし「家族の体験」が「ゲームの体験」に変わり、参照の事実には誤差があった。終端は両条件とも、同じ第一文から強制なしで残り1,227 tokensすべてを再現した。TRAIN生成の上限は参照抜粋長で、最後のtokenでの停止は外部の長さ制限によるもの。学習にない自発的EOSを成功に加えていない。

未知DEVでの退行は単に反復が増えたことにとどまらない。たとえば通常CE終端では気象の入力に「南東部にある自然豊川」という農業教材由来の表現が現れた。美術館の収蔵庫や日本武道館も無関係な入力へ流出した。TRAINの参照継続NLLは初期4.388からA 0.009、B 0.008へ改善したが、文章DEVの参照NLLは初期4.332から6.066、6.023へ悪化した。参照NLLはcontext内で採点可能な原文tokenを対象とし、原典にあるLF・EOSも含む。参照長別NLLは採点開始位置も変わる。captionには参照NLLを設けていない。既存21入力の保持は両終端0件だった。

## 解釈と再現

このモデルと推論経路には、学んだ複数文を自律生成する能力がある。今回の重みでは、未知話題に正しい履歴を渡すだけではその続きを展開できなかった。少数文章への強い特化と既存能力への干渉は実測できたが、元の基盤学習量・ジャンル分布・モデル容量のそれぞれが未知入力の失敗にどれだけ寄与したかは分離できない。二方式とも終端で暗記が飽和しており、どちらが一般に優れるかも決まらない。固定DEVは既に閲覧された開発診断で、意味判定は単独assistantによる非盲検。独立母語話者判定は未実施。正式採用はNo-Go。

PLANとTRAINは初回実行前のcommit 1件目に固定した。experiment.py の probe、各armの 0 100、100 300 を別プロセスで実行。evaluate.py に各状態名を指定する。学習とMIX-579評価は作業環境の無料CPU、残る6状態の評価は公開GitHub Actions CPU。元checkpointのSHAを検査してロードした。段階0は既存重みとPLANのfresh optimizer規約から復元する。4つの新規完全stateはartifactsに分割保存し、cold.pyでGit blobだけから復号・全chunk/全体SHA・Adam step・ledgerを照合する。直接のartifactダウンロードが作業環境で拒否されたため、成功済みの出力をActions内でGitへ転送した。先行転送ジョブ2件は回収後に取り消した。評価の再実行は行っていない。

入力別の判定と比較のための全系列を保存した。TABLESのTRAIN完全再現はtoken完全一致、caption自然候補はprefixを含む短文の評価。文章DEVの初期0条件は112 tokens、学習後の固定評価は従来どおり128 tokens。初期の従来128評価でも二文成立は0/18だった。過学習で初期モデルの公開置換は行わない。
