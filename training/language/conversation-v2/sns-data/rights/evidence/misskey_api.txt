You can contribute on Crowdin . We appreciate your cooperation 🙏. Misskey API Misskey provides a public API. You can use this API to develop Misskey clients, integrated web services, bots, and more (hereinafter referred to as "applications"). A Streaming API is also available, allowing you to build applications with real-time capabilities. Tips By using the official Misskey SDK or third-party libraries, you can simplify some of the procedures described in this document and make using the API even more convenient. Endpoints List of Libraries List of Misskey API libraries List of permissions Permissions required by the application Streaming API Using the Streaming API allows you to receive various information in real-time (e.g., new notes on the timeline, reactions, follows, etc.) and perform various operations. Obtain an access token To get started with the API, you first need to get an access token tied to the account you want to use. This document describes the steps to get an access token and then the basic API usage.
