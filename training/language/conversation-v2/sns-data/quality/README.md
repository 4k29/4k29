# 会話品質監査

PLAN.json は新しい本文を読む前に固定した選択条件。原文全体を読み、返信の意味接続と内容のある応答を別々に判定する。短い相槌や口語は日本語として不自然とは限らず、それだけを除外基準にはしない。

以下を混同しない。

- 元コーパスの権利許諾と、本文の品質採用。
- 隣接発話または返信先が存在することと、意味のある返答。
- 人間同士の実生活SNS投稿と、研究者の指示による人手の課題・ペルソナ会話。
- assistant による読解と、独立した母語話者による正式評価。
- 文字列の自然さと、人間執筆または当事者同意の証明。

原文の書き直し、自然な返答の補充、生成モデルによる正解作成は行わない。個人情報懸念がある原文は分析結果に理由を記録し、公開用監査には必要以上の引用・識別子を載せない。採用率の標本記述を母集団の保証に置き換えない。
