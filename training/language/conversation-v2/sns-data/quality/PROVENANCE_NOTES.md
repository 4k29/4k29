# 品質評価で区別する原典と対象能力

MRMPC の公式 README は、研究収集した約1,000件のうち960対話を、個人情報をマスクし倫理面で選定して公開したと説明する。本文の自然さにかかわらず、一般SNSから観測取得した自然発生スレッドではなく、初対面／家族関係を設定した人間の研究用3者チャットとして集計する。README の対話数・話者数は今回の取得・処理件数と区別し、処理結果で照合する。

`mention_to` は投稿先話者のリストで、返信先発話IDではない。直前の発話、mention先の最後の発話、話者が切り替わる箇所を自動で正しい返答ペアとみなしてはならない。会話全体を読むことで局所的な意味接続は調べられるが、公開されていない厳密な返信先を復元できたとは報告しない。

3者を現行2roleへ交互に押し込めると、同じroleに異なる人物が入る。全文保存と将来のモデル入力採用は分ける。2者部分だけ切り出しても、第三者の発話を消したことで参照や応答が成立しなくなる場合がある。新たな話者表現は別の入力契約比較とする。

個人的な経験、仕事、家族、好みは人間の発言としての学習資料であり、AI自身の事実を記述する正解回答ではない。自然な口語の基盤学習と、AIとしての指示追従・適切な自己表現は別段階とする。マスク済みでも本文全体のプライバシーが保証されるわけではない。

OASST の日本語原文が追加される場合も、crowd によるassistant役回答とSNS自然会話を分ける。`lang=ja`、元データのquality/rank、human申告は出典メタデータであり、内容の事実性・自然さ・人間執筆性の完全証明ではない。枝分かれ回答の複数branchを別々の独立会話と水増ししない。
