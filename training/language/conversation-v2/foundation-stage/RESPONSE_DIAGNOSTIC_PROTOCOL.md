# 応答目的の切り分け：事前移行条件とは別の探索診断

純原文・混合とも主24件は全文成立0、反復24であり、PLANの通常の段階移行条件は**不合格のまま**。Phase1達成、通常のPhase6進行、正式採用を宣言しない。成功基準・生成条件・失敗結果を変更しない。

追加観察では、混合条件は正解の人間会話履歴でEOS確率57.2%を保持し、日常会話入力では文法的な相槌へ戻った。しかし質問の必要内容は返せない。これは、全CEによる人間の次発話と、根拠を参照する応答目的を切り分ける価値がある。ユーザーの「正式採用と隔離した探索的学習の基準を区別する」という方針に従い、**通常移行のGoに読み替えず、独立した事後探索診断**を追加する。これは最初の運用計画への明示的な追記であり、元の事前登録条件を満たした実験とは呼ばない。

初期は混合3e-5の固定terminalを選ぶ。実行中のLR比較の出力を見てbestを選ばない。両条件は同一model/Adam/RNG、3997BPE/context256、継承LR3e-5、clip1、固定terminal、同じ全語彙greedy評価。変更はデータ配分のみ。

- A: 1,024個の元の人手QA。回答はJaQuADの原注釈spanで、生成AIの正解でも完全な人間assistant文章でもない。
- B: 同じ各batchの2QA＋2つの元日本語連続部分。全slotの入力長と教師位置/教師token数をAに厳密に一致させる。
- 全例で共通のconditional suffix CE。QAでは返答本文+EOS、原文では指定された連続suffix。自然原文の途中へEOSを挿入しない。各256更新/6,720教師targets、繰り返しQA0。各arm2回の再開照合を含み実call上限516。

原文保持側は広いTRAIN poolから選ぶため、混合初期で既読の位置と未読の位置を含み得る。新原文追加と純粋な記憶保持だけを分離した因果効果とは言わない。元々全文成立0なら、0を維持しても自然生成能力の保持成功にしない。

新契約はQAでUSER3/ASSISTANT4、原文で自然なprefix/suffix。数値IDは旧humanA/Bと同じだが意味は別。原著者IDとassistant役割を混同せず、人間の私生活をAI自身の正解にしない。QAの外枠はprogram構成、質問/回答spanは原注釈。固定48件を読解し、既知の誤注釈/抜粋で失った根拠を隔離した。残る1,396候補全件の個別人間審査や全事実確認はしておらず、正式data採用ではない。

旧DEV36/24/23、既存人手32QA、主原文24、条件反転、自己履歴を同じ条件で評価する。これらは露出済みの診断であり独立TESTではない。新しい正式能力基準を追加したり緩めたりしない。文章・必要内容・正確性・EOS/反復を分離し、source文字列の出現だけを成功にしない。TRAIN probeと未知articleのQAを区別する。

この診断が失敗しても少数QAの反復やloss係数調整を続けない。自然な基盤生成と広い人間応答資料の不足、学習量・最適化・容量を次の研究課題として残す。独立母語話者評価なし、公開置換/マージ/有料資源なし。
