# 原文の文脈長を変える継続学習

## 比較の範囲

今回調べた既存資料から、同じ後続文を自然に共有できる人間執筆の別版対は目標数に届かなかった。PR #129と同じgreedy候補監査は繰り返さず、既存原文の完全な文を残して左側だけを短縮する代替比較を実施した。

PR #127 C-300を共通の初期model・Adam・RNGとして、AにはPR #128のC-600を使用。Bは固定LR1.65e-5、clip 1.0、同じsource構成と分母で300更新。全92,025教師のうち、文章46,012、STAIR 46,013。最初の教師より左に自然な文境界を取れる57行から、残る対象・指示先・論理関係を単独で読める16 familyを審査した。対象985位置（文章の2.14%、全体の1.07%）の履歴だけを平均128.44から53.75 tokenへ短縮。全教師のラベル・順序・文章とSTAIRの配分、STAIR入力、バッチ形状は同じ。短縮した行では保持tokenの絶対位置も移動するため、履歴長と位置の効果は分離できない。

固定18件と追加7件、caption32件を5時点で比較した。Aの300・450・600は既存値、400・500だけ原ledgerと全200更新を一致させて復元した。新規独立DEVの目標10〜20件は未達。既存25件は回帰診断、追加7件は以前の学習にも露出済み。隔離1件はPR #128で取得済み。意味判定は単独・非盲検で、独立母語話者評価は実施していない。

審査対象は短縮後の履歴から直後の教師を自然に読めるかどうか。例えば蜂蜜の行で「これ」の指示先は残るが、保持文冒頭の「しかしながら」に対応する前段の対比は消える。全文の談話情報が保たれる設計とは区別する。

## 長短履歴の同一教師比較

両モデルを変更対象16行の長い履歴・短い履歴の両方で評価した。本文NLLは各条件で同一の977本文tokenを使用し、LFの8位置はこの集計から除外した。生成上限は行ごとに元の履歴が収まる最大64 tokenとし、短い履歴にも同じ上限を適用した。

|終端モデル|元の履歴NLL|短い履歴NLL|短−元|
|---|---:|---:|---:|
|A|3.89489|3.91960|+0.02471|
|B|3.91162|3.90333|−0.00829|

Bは短い履歴のNLLがAより0.01627下がり、16/16行で低下した。元の長い履歴のNLLは0.01673上がり、16/16行で上昇した。学習で与えた短い条件への適応と、長い条件での予測の低下が同時に観測された。対象はTRAINそのもの。どちらのモデル・履歴でも話題に沿った新しい文は0/16で、語句や数字の反復が残った。独立資料の頑健性や生成能力の改善には結び付いていない。

## 実行と復元

Bの保持更新300、別プロセス301更新照合1回、Aの再現更新200、計501 optimizer呼出し。記録済みforwardは6,286回。A/Bとも300/300 updateでclip、非有限値0。clip前norm中央値は3.979／3.985、MIX-579からの終端L2変位は3.95274／3.95338、追加更新の経路長は4.04439／4.04225。最初の13更新のledgerが一致し、最初の短縮を含む314更新で差が現れた。終端のTorch RNGはA/Bで同一だった。

共通300、保存A-600、新規B-600のcheckpointをGit blobのみからSHA照合して完全復元した。更新数はledgerとAdamの全stepに一致。共通開始からの301更新は別プロセスで更新値、重み、Adam、Torch RNGのdigestが一致した。全5時点の学習曲線はTABLESに記載。正式採用はNo-Go。
