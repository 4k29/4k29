# 原文と境界の審査

PR #129の人間執筆資料の監査、公開済み研究ブランチの原文・出典・候補記録を確認した。PR #129にある原文由来の変化は読点の表記差。今回の凍結資料の範囲では、後続を共用できる別版の人間執筆対を出典とともに20〜40 family分用意できなかった。版履歴全体や外部の言い換え資料を網羅した調査は行っていない。

代替比較はPR #128の文章行のうち、最初の教師より左に、第一文の後のBPE対応済み句点と、完全な一文を含む保持部分がある57行を抽出した。全文と短い履歴を読んで、参照対象と説明がつながる16行に限定した。例として「前者」「後者」の対象を切り落とす芋焼酎の行や、冒頭が「この事から」となるチンドン屋の行を除外。採用した16行の理由はCUTSに記載。平均履歴は128.44→53.75 token。変更対象985位置は文章教師46,012の2.14%、全92,025教師の1.07%。

既存のPR #128原文の出典とライセンス表示を継承し、本文の改稿は行わず左履歴を選択した。原文評価は単独・非盲検。PR #129のDEV監査で確認済みの資料は旧DEVに含まれるか、既に使用された探索DEVである。新規独立セットは確保できなかったため、学習前に既存18+7件、caption32件、PR #128で隔離した1件を固定参照とした。封印TESTは使用しない。
