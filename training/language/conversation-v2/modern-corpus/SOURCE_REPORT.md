# 新規日本語資料の取得・研究利用の確定（学習結果とは別）

最も大きい新規追加はSTAIR Captions1.2の人手による日本語場面説明文である。公式GitHubの2018年固定commit、READMEのCC BY4.0、作成論文の人手annotation手順を確認した。外部モデルの重み、tokenizer、生成回答は使用しない。

STAIRの約2,100執筆者は原論文が報告する全体の人数で、本TRAIN内で独立確認した著者数ではない。公式公開validation本文は開かず、公式TRAIN内の画像ID64familiesをDEVへ分離した。近重複42件と追加審査で問題が見つかった4件はTRAINへ入れない。画像類似性や同じ執筆者の分割間交差は不明で、独立著者評価とは呼ばない。

開発48件、別の画像familyからの64件をmain assistantが原文で読んだ。後者は事前条件60/64を満たしたが、独立した母語話者評価ではなく、全件の自然さ・写真との一致を保証しない。captionは単文・現在進行形に偏り、理由・手順・意見や対話の返信関係を備えていない。複数captionは同じ画像の別説明であり、独立した場面や独立した意味として水増ししない。

最初の選択済みcorpusは181,127単位、6,061,241本文位置、6,372,025教師targets。EOS244,716、role73,268、BOS/PAD教師0。既存抜粋の最初の7,200body位置はBOSなしの文脈入力として保持した。本文位置と教師数の差はこれらの境界で説明できる。任意の窓へEOSを挿入せず、captionは原典のannotation単位を完結単位として扱う。これを段落や文書の生成能力と同一視しない。

新規研究pool5,653,757＋既存pool4,518,175＝10,171,932本文位置。ただし、同文の自然な反復、同画像の別説明、topicや文体の相関を含む。すべてが意味的・著者的に独立した10Mtokensだと保証しない。処理targetsやA/B二条件の計算量を新規原文量へ加算しない。

原文SHA、公式固定版、取得日時、加工・除外理由、各ライセンスは各receiptとLICENSE_NOTICEに保持した。MS-COCO画像ファイルを取得・学習せず、論文PDFの図やモデル生成例もTRAINへ入れない。提供済みtokenized版を独自BPEの代用にしない。公開datasetに個人のアカウントURL・画像URLを加えず、caption/画像IDは同一データセット内のfamilyと出典確認にのみ使う。

第三者申立て・個人情報の問題はsource/annotation IDとSHAから対象・関連familyを隔離し、将来のdatasetと実験を再構築する。既存モデルからの完全unlearningやGit履歴の完全削除を実現済みとは扱わない。連絡・同意取得の実績はなく、第三者へメッセージを送っていない。

数値事前検証と実更新後の完全再開は別receiptに保存。ここでのGoは隔離研究用データの利用と事前固定した学習実行に限定する。正式モデル・公開サイトの置換、Phase1や会話能力の合格とは別である。
