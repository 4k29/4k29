# 現代日本語コーパス拡充と基盤学習（実行準備中）

GOAL.mdとPR104を引き継ぎ、自然な日本語の全文生成を測る。サブエージェントは使用しない。研究ブランチ `research/modern-japanese-corpus` / Draft PR105。

新規STAIR Captions1.2は、2018年の公式固定commitでCC BY4.0を確認した人手の日本語注釈である。公式TRAIN413,915件を独自BPEで処理し、7,196,258本文tokensの完全byte復元を確認した。論文は約2,100人の執筆者を報告するが、本TRAIN内の独立執筆者数は不明。MS-COCO画像ファイル、提供済みtokenized版、論文のモデル生成例を学習に使わない。

文形式・重複・source品質・DEV照合後の研究用候補は322,483文 /5,653,757本文tokens /82,584画像family。開発48件と、それらと画像familyを分けた追加64件を原文で読解した。追加審査は事前基準60/64を満たし、判明した不適切4件とDEV近重複42件は隔離した。これはmain assistantによる審査で、独立人間評価や写真との事実照合ではない。単文・現在進行形・視覚的場面の偏りが強く、会話や段落理解の資料とは区別する。

既存PR104の4,518,175本文token位置と合わせ、研究利用可能poolは10,171,932位置となる。新規分と再利用を分け、同じ画像への複数の説明やRPの自然な同文反復を、意味・著者の独立性と取り違えない。

最初の学習用選択は新caption2,999,999本文tokens、既存原文2,061,282、既存人間会話999,960。合計6,061,241本文位置、6,372,025教師targets、6,361更新の一巡を事前設計した。captionだけを主モデルにしないようtarget比率を約半分以下に制限する。原文を修正せず、既存のBOSなし抜粋7,200件と真のEOSを保ち、窓末端にEOSを加えない。圧縮corpusとscheduleは別コピーで再構築し4ファイルのSHA完全一致を確認した。

PR104のA/B終端重みを保持し、両者のAdamだけ共通の新規状態へする。Bはseed41029から学んできた自作fresh起源系列で、今回再初期化しない。初期dropout RNGの一致を確認し、LRは前の終了値3e-5を上限に1e-5へ減衰する。過去の学習量と今回の追加量を区別する。詳細と未実行の旧設計案は `next-foundation/EXPERIMENT_PROTOCOL.json` とhistory。

**現時点の新規optimizer更新は0回**。数値・保存資源の事前検証、両条件の実更新後再開一致を確認してから、共通2,000,891targetsと選択系列の一巡へ進む。NLLだけで系列や能力を選ばない。全語彙greedyの無修正全文、bytes、全token列を保持する。短いcaptionの補完だけでは旧厳格ゲートやPhase1を通過しない。

その他の取得結果：

- Global Voices公開記事2,676件の出典確認は完了。原文候補7,023,700tokensは外国語引用・翻訳・creditを含み、採用済み日本語量ではない。原本の不正XML70記事は修正せず出典だけ別手法で回収した。引用・転載・文脈欠損・事実誤認の問題がありTRAINへ含めない。
- 大阪市の生活手順HTML8ページを実取得（候補29,624tokens）、本文抽出や個別例外を審査中。外部コールセンター・画像・PDFは含めない。
- MAFF旧54回答と新20回答を全文読解。新規は12件が研究prose候補だが、本研究ではMAFF全体をTRAINから外し新DEVを保護する。403の3件で取得を停止し、拒否URLを回避・再試行しない。
- 青空文庫7作品20,775tokensは歴史的文体のため保留。東京都広報は再利用許諾を確認できず、観光庁の解説文は個別注意事項との条件差があり保留。政府広報オンラインは403で取得せず。
