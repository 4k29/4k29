# 段落境界における文脈利用診断

固定B-579のみを使用した研究用診断。自然な段落生成・意味理解の合格判定ではない。optimizer更新0回、モデルforward80回（主要64＋補助16）、既存logitsの同一入力再利用0件。自由生成、新規取得、checkpoint変更、学習条件変更は行っていない。

## 選択と事前固定

Bが実際に学習した凍結コーパス・scheduleのLF2直後の実教師位置から、新しい32件を選んだ。以前の8件のページに加え、既存診断32位置を除外した。「また」16件、それ以外16件。2010・2012・2014・2016・2018・2019・2020・2021年から各4件。その他群の正解は13種類、同一token最大2件である。

LF2を確認可能な実教師1,849位置から、履歴長条件外479、topic不明265、既存32位置、旧8件のページ91、UTF-8切断等3位置を除き979候補。さらにBOSなし・履歴中のtopic根拠を条件として554候補を得た。選択seed、候補順、文書・年度・ページ・見出し、原文／教師位置と除外理由はSELECTIONとPROTOCOLに保存した。実入力長は65–243tokens。

正しい履歴Cと無関係履歴Uは各32の異なるページを使い、計64ページ・64見出し。全組で年度を一致させ、意味の異なる具体的話題を選んだ。ただし、すべて環境省白書という同一出典familyであり、独立著者の標本ではない。ここでのdocument familyはHTMLページである。キーワード判定後、メインassistantが全64履歴を読んで対応を確認した。独立人間評価ではない。

Uは別ページの実学習履歴を左側から2–171tokens切断してCと同じ長さにした。再token化せず、全入力で末尾LF2、BOS等の特殊tokenなし、paddingなし、position IDsは0からL−1。入力のUTF-8復元・原文token一致・実scheduleへの対応を検証した。Uの切断履歴は元文書に対する連続部分列だが、元の正解との組合せは反実仮想であり、分布外という限界がある。

当初のtopic辞書では年度別割当が成立しなかったため、推論前に表記ゆれを追加した。また、意味的に近いU候補9組等を推論前に修正した。経緯と旧候補はhistoryに残し、対象Cの32件は変更していない。最終23ファイルのSHAをFREEZEに固定し、commit 30ec99252b124d08b95fe68684edbcf50b8a07d2として公開した後にモデルを読み込んだ。予測を見てから選択し直していない。

## 主要結果

Δ＝log P(原文token|C)−log P(同じ原文token|U)。全語彙softmaxであり、改行・特殊tokenの除外なし。

|群|Δ>0|平均Δ|中央値Δ|P(LF) C/U|P(また) C/U|
|---|---:|---:|---:|---|---|
|均等抽出32件|17/32|0.07696|0.02356|42.31% / 43.08%|6.92% / 6.69%|
|また16件|10/16|0.03485|0.04426|44.33% / 43.71%|6.63% / 6.36%|
|その他16件|7/16|0.11907|−0.02335|40.29% / 42.46%|7.21% / 7.02%|

**C/Uとも全32件でLFが1位、「また」が2位。argmax変化は0/32。** その他群の正解順位は平均61.13対69.44で、9/16件が改善したが、確率差の中央値は負であり安定した優位とはいえない。その他群の平均Δは一部の大きな正値に影響される。

平均エントロピーはC 3.8563、U 3.8346nats。平均JSは0.02294natsで、履歴によって分布は変化している。Δの範囲は−0.5343から1.0722。全32件・群別の分位点と固定bin分布はRESULTS、各例の確率・順位・上位10候補と全入力はTABLES／JSONに保存した。

例31の「土」はCで0.345%、Uで0.118%、順位30対52と改善するが、Cには土壌に関する語が既にあり、表層的な語彙の再出現でも説明できる。例26の「さ」（さらに）はCの方が低いが、参照token以外にも自然な続きが存在する。どちらも意味理解の成功・失敗を直接示さない。

## 本文8tokensの補助診断

推論前に代表8件（各群4件）と具体内容BPE片を固定した。各C/Uに同じ原文の正解続きを与え、8位置を一度のforwardで測った。自由生成ではない。

2–8位置では正しい履歴が有利なtoken位置は35/56、平均Δ 0.10688、中央値0.09293。例ごとの2–8位置平均は6/8件で正。事前指定した具体内容の20 BPE片では13/20、平均Δ 0.11829。しかし、同じ語の複数片は依存し、5例に限られる。第2位置と第8位置の平均Δは負で、一様な文脈効果ではない。正解argmaxは2–8位置でC 17/56、U 19/56である。

第1位置の平均P(LF)はC 41.91%／U 43.38%。正解の最初の本文tokenを強制入力した第2位置ではC 0.00378%／U 0.00531%へ低下し、その後も低い。「また」への確率も低下した。これは本文に入る前の境界状態に強い偏りがあることと整合する。**正解tokenを与えれば本文へ移れることは、自力で本文へ移れること、自然な段落を生成できることを意味しない。** 改行抑制の導入根拠にもしていない。

## 問いへの回答と限界

1. 文脈は確率分布に影響するが、参照tokenへの安定した優位は限定的。完全な文脈無視とはいえず、意味内容の理解が成立したともいえない。
2. 「また」はUでも2位で、正解が別tokenの群でも同程度以上の確率を持つ。汎用的な段落開始priorが強い仮説を支持するが、データ頻度による因果の証明ではない。
3. 正しい履歴でもLFが全件1位に残った。P(LF)の変化はまた群では上昇、その他群では低下し、境界バイアスは文脈差を越えて残る。
4. 本文開始後に一部の内容語予測で文脈の利点が見えるが、共通の正解prefix自体が強い条件となる。自己生成履歴の安定性は今回測っていない。
5. 次の学習では、境界から本文へ遷移する学習契約を優先して検証する価値がある。学習量、最適化、容量の制約は依然未確定であり、Attentionの欠陥や容量不足は断定しない。

16対16は実学習の「また」13.01%と異なる。年度も均等で、32件平均を母集団の推定値と扱わない。同一年・同一出典の相関があり、有意性を主張しない。長めのBOSなし履歴、topic辞書、手作業の無関係判定による選択バイアスがある。切断位置、内部の改行や句読点、語彙重複は完全には一致させておらず、純粋な意味だけの因果比較ではない。旧失敗8件との確率差を改善率として比較しない。初期モデル・A系列の新規推論は行っておらず、ここでの境界バイアスは固定Bの本文開始第1位置を指す。

## 次に試す研究は一つ

同一の原文・初期全状態で、段落区切りの学習表現をLF2のままにする条件とLF1へ変換する条件を比較する。原典と変換履歴を別保存し、本文順序・真のEOSを維持する。モデル・独自BPE・context・loss・Adam・LR・評価は共通とし、元本文の教師位置予算を合わせる。区切り教師数、全targets、位置・窓長の差は別計測し、「改行数だけ」の純粋効果とは呼ばない。今回の結果から成功を保証せず、全語彙greedyで本文への遷移と全文成立を事前固定して評価する。この実験は今回未実施。
