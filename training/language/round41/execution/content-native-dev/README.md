# Supplementary mid-dialogue DEV, never a replacement gate

Eight unique contexts fixed before any model generation on these contexts. Original human texts, no persona/role labels, original order and newline serialization. Selection is deterministic from the existing99 exposed humanDEV records: one source per context, begin at utterance index4 or later, current utterance30–100 Unicode characters and total own canonical prefix<=64 tokens including BOS; include the preceding original turn only if it fits. Source ranking, source hashes and true utterance indices are saved. No expected answers are used. These are additional exposed DEV, not a fresh TEST or evidence of unseen generalization. The earlier four greeting-heavy probes had only three unique prefixes; they cannot support a general format conclusion.

No profiles, LLM-system logs or generated teacher answers. Development speakers are disjoint from admitted TRAIN speakers by the pre-existing source fold. Short/fuzzy overlaps are not ruled out.

Freeze SHA is the probes.json byte SHA recorded at creation and in Git before generation. This evaluation never modifies training policy, sources, LR, checkpoints or selection. Compare old/new raw generations at192 greedy tokens; retain every token and character, failure and EOS flag. Separate ambiguous loop classifications. Original17 and daily12 strict gates remain unchanged. Python/JavaScript results for this supplementary set, when run, are saved explicitly; never infer numerical parity or semantic scores from other probes.
