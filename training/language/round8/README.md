# 原文追加と自作モデルの拡張

round6の追加10,000更新では第一文3/9・全文非反復1/9が変わらず、文章生成は不合格だった。今回は保存済みのMDN日本語原文1,457文書を追加し、自作4層モデルを8層に拡張して追加10,000更新を実行する。予定回数と完了回数は区別する。

原文は計2,549文書。以前の1,092文書の分割・原文単位をそのまま保持し、新しい未露出グループだけを分割した。作品・著者・サイトと80文字以上の完全一致段落を同じグループにまとめる。TRAIN1,967文書／8,721原文単位／4,861,881文字、VAL169文書、TEST209文書。MDNのHTMLアーカイブとCC-BY-SAの利用条件・作者表示はround7に保存してある。documents.jsonl内の新規htmlArchiveはround7基準の相対パスで、今回のディレクトリ内のパスではない。旧原文の出典・利用条件はround3を参照する。抜粋した段落にはコードや図の前提が欠ける場合がある。

TRAINで観測した4,315文字だけを文字単位に組み立てる。既存token IDと結合順位を保持して75規則を末尾に追加し、語彙4,840、語単位の結合0。未知の文字には元のbyte表現を使う。検証文で語彙を学習しない。

親はround6の実10,000更新後にVALで選択した8,000更新時点のown重みで、選択された系譜は18,000更新。追加4ブロックの残差出力を0、新規文字行を0として、既存logitを保持して初期化する。全パラメータは学習可能。語彙が増えるため初期softmaxとNLLが親と同じとは限らない。拡張前後の因果を一つの変更だけに帰属させない。主比較は同じ拡張モデルの初期0更新と、今回の実10,000更新後にVAL NLL/UTF8 byteで選択した重み。

8層／dim192／4heads／4,537,728パラメータ、context256、lookback32。CPU2threads、batch8、BF16 activation、FP32重み・optimizer・検証・推論。AdamWをリセットしseed1829、LR0.00015。samplingは青空.35／MDN.25／気象庁.15／総務省.10／環境省.10／農水省.05。原文の全ラベルと実際の境界を保持し、長さ64/128/256にまとめて余分なpaddingを減らす。

開発生成は旧9件にMDN4件を追加した13件。同じ全語彙greedy、最大192新token、補修・反復penalty・文字フィルタなし。第一文9点以上、文法2、接続2、終止と有効tokenを要求する。物語・現代説明文のそれぞれで第一文80%以上と全文非反復90%以上が必要で、旧9件だけの基準も同時に通る必要がある。短い第一文の成功は全文の意味や事実の正しさを保証しない。採点は独立した人間による盲検評価ではない。TEST30件の生成、QA学習、公開モデル切替は言語基準が成立するまで保留する。

Wikipedia、外部重み、外部Tokenizer、外部推論API、教師生成文は使わない。学習中のコード・原文・分割・語彙・親checkpointはSHAで固定する。実optimizerカウンターとRNGを保存して復帰可能にする。

```sh
python training/language/round8/train.py --merges 4578 --steps 10000 --dim 192 --layers 8 --heads 4 --batch 8 --threads 2 --seed 1829 --lr 0.00015 --validation-every 1000 --run expanded-characters-10000 --compile --precision bfloat16
```
