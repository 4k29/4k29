# 対話品質の評価

## 現在の日本語・仕様値の評価

`node evaluation/evaluate-japanese.mjs` は、本人の指定・趣味の分類・会話の続き・仕様の条件・説明の口調を扱う41問を、2口調×3長さ×10回、計2,460回答で検証する。根拠と回答対象、質問との関連、既知の文法不良、本人が直接答える視点、名前だけなどの形式の5項目をすべて満たす必要がある。結果は `japanese-conversation-results.json`。これは開発時に修正へ使った自動回帰ルーブリックで、未知の日本語を人間並みに話せることや社会的な会話能力全般の保証ではない。

初回32問の1,920回答では1,830通過、60回答でkyuの「それについて詳しく」が文脈を失い、30回答で判定器が自然な「非対応だよ」を誤検出した。文脈処理と判定器を修正し、32問は1,920/1,920。その後、語尾変換の「使います→使いるよ」と、詳しく説明する指示を解析した後に質問の説明意図を失う問題を修正し、38問2,280/2,280を確認した。判定器の誤検出修正も含むため、通過件数の増加をすべてモデル性能の向上とは扱わない。

`tests/product-specifications.test.mjs` は、自作Transformerのgreedy生成が日英66仕様値とドラマ紹介4文で70/70完全一致することを確認する。数値を辞書から返した結果ではなく、学習したtensorから実行したトークン列を検証する。結果は `specification-recall-results.json`。既知値の記憶の再現であり、未知の知識への汎化評価ではない。runtimeでは同梱した公式値と照合し、誤った数値を表示しない。

最新の確認には、裸の「MERは？」の前置き除去、音響機器の簡潔な言い方、機種名を繰り返さない仕様の段落、語尾の一律変換の除去も含む。現在は41問2,460/2,460、Node 790件を通過。

最新の採点での変更には本人の指定に伴う正解更新も含む。趣味にTecircを含めず、好きなものは名前のみ、ドラマの説明は主演とTBSの日曜劇場のみ。新たに確認した音響機器のバッテリーは仕様として回答する一方、価格・購入歴・所有の未共有情報は答えない。従来の「未登録」だった仕様を正解へ更新したことを、純粋なモデル改善とは見なさない。

`node evaluation/evaluate.mjs` は40問の評価を実行する。`node evaluation/evaluate.mjs . validation.json` は開発中に見直した20問、`node evaluation/evaluate.mjs . holdout.json` はその修正後に用意して確認した10問を実行する。第二引数に別のチェックアウトのルートを指定すれば変更前と比較できる。

評価ファイルはサイトの質問判定や学習に読み込まない。登録情報から返すべきfactIdsの集合を正解とし、未登録の質問は空集合と所定のUnknown応答を確認する。言い回しの文字列は評価基準にせず、文章の自然さ、重複、根拠の保持は別の回帰テストで確認する。

## 複合質問と文脈参照の評価（2026-10-04）

`node evaluation/evaluate.mjs . quality.json` は追加49ケースを実行する。`setup` は直前の会話、`unanswered` は未登録の部分を正しく識別したか、`links` は返すべきリンクURLの集合を指定する。質問された複数の機器、話題や所有者の省略、推しと本人のリンク、購入場所などの未登録属性を検証する。

`quality-results.json` に変更前の `c8ecb97524fb17252c1f98eba2534ff795ba909b` との比較を記録した。既存の日英126問は126/126を維持し、追加49ケースは14/49から49/49へ改善した。追加ケースは開発・修正に使った回帰データであり、独立した汎化性能の推定ではない。前の20問のholdoutも今回再実行した固定回帰として扱う。

「分野」を尋ねた場合に企業・ブランドを混ぜないよう、意図判定用の既存例「気になっている分野について聞きたい」のラベルも関心全般から分野のみへ修正した。これは質問例の分類修正であり、本人の登録情報の追加ではない。

results.jsonはmainの3c11806との比較。開発用60問は56→60、調整に使わなかった10問は9→10。合計65/70→70/70。これは固定した範囲の評価であり、一般のあらゆる日本語質問で100%正答するという意味ではない。40問と20問は開発時に確認・修正したため、独立した汎化性能の推定には使わない。今後の失敗例はまず回帰へ追加し、別の評価例で確認する。

## Transformer・次の語句の予測・個人設定（2026-10-04）

`prediction.json` はさらに追加した44ケース。口調・長さの指示の前後、文脈リンク、未知の属性、友達の所有物と本人の愛用品の区別を含む。修正に使った開発・回帰データである。全7ファイルの固定回帰は219ケースとなる。

`node evaluation/evaluate-prediction.mjs` は現在の回答のfactIds・リンク、追加168質問の対応、16回の言い回しの繰り返し、モデルサイズ、CPU応答時間、学習に含めない26文のトークン予測を確認する。以前のソースのスナップショットを最初の引数に渡すと比較できる。`--out=evaluation/prediction-results.json` で詳細を保存する。

現在の保存結果は600,000回の追加学習後。固定回帰219/219、追加質問168/168、好きなもの22/22。以前のスナップショットとの比較は、イヤホン・ヘッドホンの統合やkyuの追加など正解条件の変更も含むため、差をTransformer単体の効果とは解釈しない。前回の10,000更新と500,000更新の結果もそれぞれ別のJSONに残す。

代表7質問の16回答では9〜15種類の表現があり、factIdsとリンクを保持した。未見26文・297トークンの損失は2.09622、perplexity 8.13537。この有限の句の評価は学習やチェックポイント選択に使わない。一般の質問の正答率を示す数字ではない。

本人向けの新しい言い換え、基本説明、計算は `knowledge-calculator.test.mjs` で別に確認する。公開情報39項目と計算を、自由な一般知識モデルの能力とは区別する。外部の学習済みモデルは配信しない。学習方法と出所は [training/README.md](../training/README.md)、紹介の出典は [research/favorites.md](../research/favorites.md)。

現在のv5のウォーム300回答は中央値約1.20ms、p95約3.04ms。初回実行・HTTP取得・表示アニメーションは含まない。語句の未見26文はperplexity 8.46083で、前段階からの全般的な言語能力向上は示していない。仕様値の再現、回答ルールの修正、句の予測性能は別に評価する。
